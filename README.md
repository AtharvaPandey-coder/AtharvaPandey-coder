### 🚀 Featured Projects

**[Fintech Support Ticket Triage Agent](https://github.com/AtharvaPandey-coder/Fintech-Support-Ticket-Triage-Agent)**
ML + LangChain/RAG system that classifies customer complaints, retrieves grounded policy, drafts a response, self-critiques for hallucination, and decides next action.

**[Personal Portfolio Chatbot (RAG)](https://github.com/AtharvaPandey-coder/-Personal-Portfolio-Chatbot-RAG-)**
RAG-powered portfolio chatbot built with LangChain, FAISS, and Gemini — answers visitor questions about me with source citations and hallucination checks.

**[Mental Health Text Analyzer](https://github.com/AtharvaPandey-coder/Mental-Health-Analyzer)**
BiLSTM-based NLP system classifying mental health text into 7 categories with personalized wellness tips — TensorFlow, NLTK, Streamlit.

**[AI Contract/Policy Comparator](https://github.com/AtharvaPandey-coder/AI-Contract-Policy-Comparator)**
Agentic system comparing two contract/policy PDFs clause-by-clause using semantic similarity search (FAISS + sentence-transformers) and an LLM (Groq) to classify and flag risk of each change.

**[Multi-Agent Research System](https://github.com/AtharvaPandey-coder/Multi-Agent-Reasearch-System)**
Multi-tool AI research agent built with LangChain — routes queries across document search, web search, and Wikipedia, using Groq for fast tool-routing and Gemini for final answer synthesis.

**[Power Consumption Forecasting](https://github.com/AtharvaPandey-coder/Power-Consumption)**
LSTM-based electricity power consumption forecasting using time series analysis, deployed with Streamlit.
